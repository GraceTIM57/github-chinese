GitHub 中文化插件

让 GitHub，说中文。

菜单、按钮、时间与仓库描述——界面全面中文化，词库持续更新。

立即安装 查看源码

为中文开发者扫清界面障碍

从导航到议题，常用界面元素自动翻译，读起来更省心。

  • 全面中文化

    菜单栏、标题、按钮等界面元素按页面精细匹配。

  • 智能正则

    动态文案也能命中，减少漏译与硬编码死角。

  • 描述可译

    仓库与 Gist 简介支持一键人机翻译。

  • 时间本地化

    相对时间与日期表达自动贴近中文习惯。

三步装好，刷新即用

先安装脚本管理器，再选择安装源，回到 GitHub 刷新页面即可生效。

  1. 1

    安装脚本管理器

    推荐 Tampermonkey；也可用 Violentmonkey、Macaque、Stay 等。

  2. 2

    选择安装源

    GitHub 源 开发版 · 词库更新更勤 南大镜像 开发版 · 国内访问更稳 GreasyFork 稳定版 · 同步节奏更稳
  3. 3

    刷新 GitHub

    打开任意 GitHub 页面并刷新。若无效，请在浏览器扩展中开启「开发者模式」与「允许运行用户脚本」。
